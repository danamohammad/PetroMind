Engineering modules · methods and scope

Version 1.6 runs all numerical models on hosted servers and retains engineering workflows beside the existing compositional PVT model. New examples are explicitly synthetic. A working calculation, numerical test or fitted curve is not field validation.

Fitting and diagnostics

Fits report convergence, scaled Jacobian rank and active bounds. SCAL parameters can be applied only for an eligible fit. History candidates remain visible with qualifications. Validation rows are excluded from fitting. Numerical rank does not prove physical uniqueness. New modules save studies separately from the PVT project; use each module’s Save study and Export study JSON controls.

Equations and source references

  • OPM Flow reference manual and OPM Brooks–Corey material law: relative-permeability and drainage-capillary-pressure conventions.
  • Whitson IPR/VLP methods: linear and composite Vogel inflow. Composite flow joins continuously at bubble pressure.
  • Fluids friction documentation: Darcy friction factor, laminar 64/Re and turbulent Haaland approximation. PetroMind blends across Re 2300–4000; transition predictions are approximate.
  • OPM ResInsight decline analysis: Arps rate-time models. PetroMind adds a continuous terminal exponential segment, capacity cap and economic cutoff.
  • SciPy bounded least squares: numerical fitting implementation. Python dependency versions are pinned in Server Requirements.txt.
  • Cloudflare Qwen3-30B-A3B-FP8: hosted open-weight language model. Qwen model card and Apache 2.0 license. Matching PetroMind method references are shown with each explanation; they are not independent verification of generated claims.

Privacy and operation

Scientific calculations and predictor training run on the Render server. Calculation inputs are sent through Cloudflare when you calculate; temporary job results are held in server memory and removed after retrieval or expiry. Assistant questions and selected summaries go to Cloudflare Workers AI. No scientific Python runtime or AI weights load in your browser. Forms, charts, CSV editing and project storage remain in the browser; export project backups. Free hosting has shared limits and may take about a minute to wake. No local fallback is used. Stop waiting cancels receipt of an AI answer; remote inference may already be running. Scientific cancellation sends a delete request that terminates the isolated job process. Telemetry is read-only and session-only; its server checks refresh periodically.

None of these new modules transfers reference calibration to Halfaya or Sarta. Use matching measurements, well conditions and appropriate physical models before relying on a prediction.
